# Recursos visuais

- `docs/design-reference/*.png`: três referências conceituais fornecidas pelo usuário no repositório inicial. Utilizadas para direção artística; não embutidas na aplicação. Não é assumida licença de redistribuição fora deste projeto.
- `public/paper-grain.svg`: textura procedural original com feTurbulence, criada nesta implementação.
- `public/wood-grain.svg`: textura procedural original de madeira com feTurbulence anisotrópico.
- `app/icon.svg`: ícone original de estrela em uma cartela roxa.
- Canetas, tinta, papel, bolas e estojo: CSS original. Ícones: paths SVG originais em `components/ui/Icon.tsx`.
- Nunito e Kalam: pacotes `@fontsource/nunito` e `@fontsource/kalam`, arquivos servidos localmente. Fontes sob SIL Open Font License 1.1 (licenças copiadas dos pacotes para `public/fonts/LICENSE-kalam.txt` e `public/fonts/LICENSE-nunito.txt`); nenhuma requisição para Google Fonts no runtime/build.

Referências oficiais de implementação: [Next.js](https://nextjs.org/docs/app/getting-started/installation), [Tailwind](https://tailwindcss.com/docs/installation/framework-guides/nextjs), [Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).

- `docs/qa/*.png`: capturas originais do app a 390px, geradas pelo smoke em 2026-10-06; dados de teste locais. Não são assets de runtime.
